# Contributing

Thanks for your interest in contributing to this list!

## Guidelines

- Search existing entries before adding a new one
- Use the existing format: `[Name](URL) — Brief description`
- Tools must be currently maintained and accessible
- Free tools are preferred, but paid tools with genuine value are welcome
- No affiliate links
- One tool per pull request

## Adding a Tool

1. Fork this repository
2. Add your tool to the appropriate category
3. Submit a pull request with a brief description of the tool

## Quality Standards

- The tool must actually work and be useful
- No vaporware or tools that are just landing pages
- AI tools should produce meaningfully better results than a basic template
